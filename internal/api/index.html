// gitective
Git history, decoded
Gitective reads your git commit history and classifies each author into a personality. Then pipes it through Style Engine for output that actually reads well.

Gitective

A Go CLI that ingests git log, analyzes commit messages, author patterns, and diff complexity, then classifies contributors into seven distinct personalities. Integrated directly with Style Engine to render results in any voice.

# Install go install github.com/sofelaisrael/gitective@latest # Analyze a repo gitective analyze --style cyberpunk-commit # Pipe to Style Engine gitective analyze | style-engine --style shakespeare

// architecture
How it flows
Three components, one pipeline. Clean, modular, composable.

Gitective CLI

  • Ingests git log history
  • Classifies authors into personalities
  • Outputs structured JSON per commit
-->

Style Engine

  • Receives text + style profile
  • Applies intensity + constraints
  • Self-validates output quality
-->

LLM Provider

  • OpenAI, Anthropic, Ollama...
  • Style profiles as system prompts
  • Retry + fallback on failure

Style Profiles

7 built-in profiles: shakespeare, pirate, corporate, genz, victorian, cyberpunk-commit, renaissance-commit. Create custom ones with YAML.

Compliance Scoring

Every output is scored 0-1 against the style profile constraints. Guarantees quality or retries automatically.

Retry Loop

Failed compliance? The engine retries with adjusted prompts, escalating through fallback providers until the score passes.
